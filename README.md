# Oracle Database 26ai DBA Project

## Overview

A hands-on Oracle Database 26ai DBA portfolio built across multiple Oracle Linux lab environments.

The project focuses on practical database administration, troubleshooting, backup and recovery, migration, performance, security, high availability, and automation.

## What I'm Building

| Area                    | Hands-on Focus                                               |
| ----------------------- | ------------------------------------------------------------ |
| 🖥️ Environment         | Oracle Linux, storage, networking, Oracle environment        |
| 🏗️ Administration      | CDB/PDB, users, schemas, tablespaces, database configuration |
| 💾 Backup & Recovery    | RMAN, restore, recovery, archive logs                        |
| 🔄 Migration            | Data Pump, PDB migration, database-to-database migration     |
| 🛠️ Upgrades & Patching | OPatch, RUs, `datapatch`, upgrade procedures                 |
| 📊 Monitoring           | Alert logs, ADR, trace files, sessions, locks, health checks |
| ⚡ Performance           | AWR, ASH, ADDM, SQL tuning, memory and I/O                   |
| 🔐 Security             | Users, roles, privileges, auditing, TDE                      |
| 🛡️ HA/DR               | Data Guard, RAC, ASM, GoldenGate                             |
| 🤖 Automation           | Bash and SQL DBA scripts                                     |
| 📚 Documentation        | Runbooks, incident reports, architecture and troubleshooting |

## Lab Environment

* Oracle Database 26ai
* Oracle Linux 9
* Multiple virtual machines
* CDB/PDB architecture
* Source and target database environments
* Oracle networking and SSH

## Project Approach

Learn → Build → Test → Troubleshoot → Document → Automate
